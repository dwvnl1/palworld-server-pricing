## 下单前值得确认的五件事

1. **新用户资格。** 活动价多数只认新用户首单，老账号看到的是另一套价格。如果账号已用过腾讯云，看看家人账号或换用其他厂商，比硬买原价划算。
2. **地域。** 云服务器创建后地域不能修改，买错只能重买。按玩家分布就近选，华北选北京、华南选广州、华东选上海。
3. **流量包。** 入门档含 2000GB 月流量，正常联机用不完，超出部分按所在地域标准单独结算。
4. **端口。** 幻兽帕鲁走 UDP 8211。腾讯云这套预装镜像会自动放通，省一步；多数其他云平台要自己去安全组手动开。
5. **到期时间。** 实例到期后进入待回收状态，有 15 天保留期，15 天内没续费就会被释放，数据清空不可恢复。开自动快照，按实际占用空间计费。

单看首月，腾讯云不是最便宜的。阿里云 4 核 16G、10M 带宽有 30 元/月、90 元/3 个月的报价；京东云 4 核 16G、5M 带宽、1000GB 月流量那档起步 26.5 元/月。
